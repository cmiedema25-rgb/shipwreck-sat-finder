1. Open phone Chrome to the LAN or hosted URL (or installed PWA / Android WebView app).
2. Show Cape Henry Sentinel-2 preview; tap Detect and identify.
3. Overlay: cyan = NOAA catalog pins; yellow = CV candidates.

6. Call out metrics honestly (precision/recall may be partial on submerged wrecks).
7. Optional: Install app / Add to Home Screen on Android; mention Play AAB path is packaged but not claimed live on store.
