# Privacy Policy - Shipwreck Sat Finder

Last updated: 2026-09-04

Shipwreck Sat Finder is a research/demo app that shows open satellite imagery chips and public NOAA wreck catalog points.

## Data processed
- Scene selection, detection parameters, and API requests to your own backend.
- Imagery: Copernicus Sentinel-2 (open). Labels: NOAA AWOIS/ENC public records.
- No account required for the demo.
- No intentional collection of contacts or payment data.

## Location
Demo uses a fixed sample AOI (Cape Henry approaches). Coordinates place map pins only.

## Network
Android/PWA may call a user-configured API host. Use a host you trust.
